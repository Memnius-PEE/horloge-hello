# Mode d'emploi

1. Ouvrir <https://memnius-pee.github.io/horloge-hello/>, ou `site/index.html` dans un navigateur.
2. L'heure s'affiche et se met à jour chaque seconde, à l'heure de l'ordinateur.
3. Cliquer sur « Dire bonjour » : la page écrit « Hello world ».

La page n'envoie rien et ne garde rien : tout se passe dans le navigateur.
